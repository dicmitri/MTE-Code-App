# Search source coverage review

This is editorial evidence for source revision `56b5f0ef982f413a10fd85d0c1c76b3070cad84a`, not runtime search data. The September 2024 Code and October 2025 Disclosure Guidelines remain distinct authorities. The source manifest freezes original bytes; it does not replace the publication verification manifests.

The register covers all 29 non-changelog Code and Disclosure units, 83 sections, 54 Q&As, 38 glossary definitions, 38 published table rows, 14 footnotes, and 11 CSV header fields: 238 records with 713 reviewed concepts and ordinary-language queries. Code page references are verified chapter/unit ranges from the PDF-derived Word bookmarks; JSON pointers locate exact runtime text. Disclosure page references come from pinned source metadata.

Every concept has an original and current search measurement plus a final editorial disposition. `already covered` requires the exact indexed source passage or an attached Q&A that directly answers the query in the first three results. A source literal by itself is insufficient. The current 208-group phrasebook places direct answers in the top three for 594 of 698 queries with indexed source targets, compared with 570 at the pinned original stage. Some retrieved passages remain labelled `unsafe association` or `refine/remove` because rank does not override the source distinction. The final register records 583 `already covered`, 100 indexed `retrieval gap`, 16 `indexing limitation`, 9 `unsafe association`, and 5 `refine/remove` dispositions; none remain pending. The 100 gaps are explicit rather than assumed to be solvable by a safe synonym.

The 11 CSV fields are a separate indexing gap: Annex I contains a download sentence, but the field names are absent from searchable reader text. Four glossary overview queries lack a single indexed section document because definitions are indexed separately. The Annex I template-fields query also needs the CSV field text. Phrasebook rules cannot index these records.

The second source pass considered unresolved query wordings against the source and both indexes. Broad topic queries, section-overlap misses, and edition-specific distinctions do not justify adding equivalences that would distort other results. In particular, `employee time` misses the detailed in-kind expertise passage, but a phrase matching the publication's exact Member Company wording is too narrow for the shared general-English vocabulary. It remains a documented retrieval gap. A generic `grant purpose`/`purpose of grant` to `purpose`/`object` bridge now retrieves the Optional Object Specification without embedding its edition-specific educational-grant category in the phrasebook. A loaned product is not necessarily a defined Evaluation Product; `loaner` remains an unsafe association. No further source-grounded, safely reusable phrasebook bridge was accepted in this pass.

The register is finite query evidence, not a guarantee about all possible user wording. Keep edition-specific dates, permissions, amounts, geographical outcomes and category definitions out of general-English phrasebook entries. Run `node docs/search-review/measure-coverage.mjs` then `node docs/search-review/finalize-coverage.mjs` after a phrasebook revision, and review any changed dispositions before using these counts.
